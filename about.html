关于本站

这是一个用 Markdown 维护、由脚本构建的静态学习日志，托管在 GitHub Pages 上。

为什么会有这个站

VLA 这个方向更新很快，论文密度高，读的时候容易「每篇都懂了，连起来还是不会」。于是决定按依赖关系重写一遍自己的理解，写成能被检索、能被修订的记录，而不是散在笔记软件里的碎片。

这个站点的组织方式只有一条原则：每篇回答一个具体问题。不复述摘要，不堆术语，写清楚「为什么是这样」。
