# 写作与发布说明

## 一、整体流程

```text
本地 Markdown  ──build.py──►  notes/*.html + index.html + notes.html
                              │
                              └──publish.py──►  git commit ──►  GitHub ──►  Pages
```

站点没有构建服务、没有依赖包，只需要 Python 3。构建产物（`notes/*.html` 等）与源文件（`content/*.md`）一起提交，所以 GitHub Pages 用「分支 + 根目录」的默认方式就能直接托管。

## 二、第一次把站点放上 GitHub

### 1. 创建仓库

在 GitHub 上新建一个公开仓库（名字随意，例如 `vla-notes`），**不要**勾选初始化 README，否则推送时会冲突。

### 2. 配置站点信息

编辑 `site.json`：

```json
{
  "owner": "你的 GitHub 用户名",
  "repo": "vla-notes",
  "branch": "main",
  "repo_url": "https://github.com/你的用户名/vla-notes"
}
```

### 3. 准备 token

GitHub → 头像 → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token：

- 勾选 **repo**（读仓库、写仓库、改 Pages 设置的权限）
- 有效期按需，长期使用建议 90 天以上
- 生成后只显示一次，先复制下来

把 token 放进环境变量，不要写进任何被提交的文件：

```bash
export GITHUB_TOKEN=ghp_xxxxxxxxxxxxxxxx
```

### 4. 推送

```bash
cd vla-notes
python3 tools/publish.py up
```

看到 `已推送到 https://github.com/<用户名>/vla-notes` 就成功了。

### 5. 开启 Pages

仓库 Settings → Pages → Source 选 `Deploy from a branch` → 分支 `main`、目录 `/ (root)` → Save。

约 1～2 分钟后访问 `https://<用户名>.github.io/<vla-notes>/`。如果 404，先等两分钟再刷新，再检查 Actions/Pages 里的状态。

## 三、日常写作

### 新建一篇

```bash
python3 tools/publish.py new "评测指标怎么读"
# 编辑 content/00x-xxx.md
python3 tools/build.py          # 只看构建结果
python3 tools/publish.py up     # 构建 + 提交 + 推送
```

### 导入已有的本地笔记

```bash
python3 tools/publish.py up ~/Documents/notes/vla/xxx.md
```

脚本会：

1. 把 md 复制到 `content/`，自动加序号前缀（`003-xxx.md`）
2. 遇到同名文件不会覆盖，会自动换一个序号
3. 图片（png/jpg/webp/svg）复制到 `assets/img/`
4. 构建全站，提交并推送

导入之后请打开文件检查 front matter：`title`、`tags`、`summary`、`order` 四项决定了它在列表里怎么显示。

### 在正文里引用图片

```markdown
![对比图](assets/img/action-head-compare.png)
```

构建时会自动把相对路径补成笔记页可用的 `../assets/img/...`，不用手写前缀。

## 四、常见问题

**推送报 403 / authentication failed**：token 没有 `repo` 权限，或已过期；也可能是 token 前后带了空格。

**页面上出现 404，但本地预览正常**：Pages 还在构建；或者仓库 Settings → Pages 的分支填错（应是 `main` + `/ (root)`）。

**新笔记没出现在列表里**：`content/` 下文件名必须以 `.md` 结尾，且 front matter 的 `type` 不是 `page`；改完必须重新 `build.py`。

**中文字体没生效**：站点字体走 `miaoda.feishu.cn` 的自托管镜像，若被网络拦截会回退到系统字体，不影响阅读。

**想换站点标题 / 描述**：改 `site.json` 的 `title`、`subtitle`、`description`，重新构建。

**想改配色**：`assets/css/site.css` 顶部 `:root` 里的变量，改一处即可全局生效。
