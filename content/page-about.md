## 为什么会有这个站

VLA 这个方向更新很快，论文密度高，读的时候容易「每篇都懂了，连起来还是不会」。于是决定按依赖关系重写一遍自己的理解，写成能被检索、能被修订的记录，而不是散在笔记软件里的碎片。

这个站点的组织方式只有一条原则：**每篇回答一个具体问题**。不复述摘要，不堆术语，写清楚「为什么是这样」。

## 站点怎么维护

所有正文放在仓库的 `content/` 目录，用 Markdown 写，带一段 front matter：

```markdown
---
title: 标题
date: 2026-11-18
tags: 概念, 入门
summary: 一句话说清这篇回答什么问题
order: 8
slug: my-note
---
```

改完运行一条命令，脚本会生成 HTML、目录、上一篇下一篇，并顺手提交推送到 GitHub：

```bash
python3 tools/publish.py up content/008-my-note.md
```

站点是纯静态的，没有构建服务，也没有追踪脚本。想在本地看效果：

```bash
python3 tools/publish.py serve
# 浏览器打开 http://localhost:8000
```
