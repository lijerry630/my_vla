## 三段式结构

几乎所有 VLA 都能拆成三段：**视觉编码 + 语言/多模态主干 + 动作头**。

```text
图像 ──► 视觉编码器 ──┐
                     ├──► VLM 主干 ──► 动作头 ──► 动作 chunk
指令 ──► tokenizer ──┘        ▲
本体状态 ─────────────────────┘（部分模型才有）
```

`PaliGemma`、`Llama`、`Qwen2-VL`、`Florence-2` 是常见主干选择：视觉 token 与文本 token 拼在一起进同一个 Transformer，输出的隐状态再交给动作头。主干决定了「看懂多少」，动作头决定了「做得多准」。

## 四种动作头

| 类型 | 代表做法 | 建模能力 | 代价 |
| --- | --- | --- | --- |
| 离散 bin | 每维切成 256 个区间，用交叉熵预测 | 训练稳定，可复用语言词表 | 量化误差，精细操作受限 |
| 回归 MLP | L1 / L2 直接回归连续值 | 简单、推理快 | 多峰分布下会平均化，动作变糊 |
| 扩散头 | DDPM 去噪一个动作 chunk | 多模态分布建模强 | 采样步数多，慢 |
| 流匹配 | 学一个从噪声到动作的速度场 | 强，且 1～10 步可采样 | 训练目标需要仔细调 |

离散 bin 的做法很直观：把每维动作按训练集的分位数切成 256 个格子，预测落在哪个格子，再取格心还原成实数。OpenVLA 用的就是这套，好处是能直接套用现成的语言模型头，坏处是装配任务里几毫米的精度会被量化吃掉。

流匹配则是连续路线的主流。它学的是「从噪声 $x_0$ 到真实动作 $x_1$ 的直线路径上的速度」：

$$
x_t = (1 - t)\,x_0 + t\,x_1,\qquad \mathcal{L} = \mathbb{E}_{t,x_0,x_1}\left\| v_\theta(x_t, t) - (x_1 - x_0) \right\|^2
$$

推理时从 $x_0 \sim \mathcal{N}(0, I)$ 出发，用 1～10 步欧拉积分推到 $x_1$，得到整段动作 chunk。这也是为什么 π0 系列能做到高控制频率：一次前向就给一段动作，而不是一步一采样。

## 双系统：慢思考，快执行

单一模型同时负责「理解复杂指令」和「30 Hz 输出」很吃力。于是有了双系统分层：

- **慢系统**（VLM 主干部份，几 Hz）：读图读指令，产出语义特征或子任务意图
- **快系统**（小 DiT 或流匹配专家，几十 Hz）：吃视觉特征 + 本体状态，高频吐动作

π0 的做法是把动作专家与 VLM 主干放在同一个模型里，动作专家只看主干的中层特征；GR00T N1 系列是更显式的多路结构：视觉语言层、扩散变换层分工。共同点是**参数量的绝大部分给理解，频率任务交给小得多的执行模块**。

## 参数与频率的账

设控制频率 $f$、单次推理延迟 $T$、chunk 长度 $k$，那么有效执行频率约为 $f = k / T$。这条式子解释了两条工程事实：

- 缩短 chunk、加快单次推理 → 反应灵敏，但误差累积快、抖动大
- 拉长 chunk → 平滑，但遇到扰动时来不及纠正

实际部署里常用**动作分块 + 滚动重规划**：执行 chunk 的前几步，就用新观测重算下一段，用「重叠执行」换稳定性。这一步做不好，仿真里 95% 的策略在真机上会明显掉分。

## 一次前向在做什么

```python
# 概念示意，不是任何具体模型的实现
def policy_step(obs, instruction, state):
    tokens = tokenize(instruction)                    # 文本
    visual = vision_encoder(obs.images)               # 多路图像 -> tokens
    seq = concat(visual, tokens, project(state))      # 本体状态常投影后拼入
    hidden = vlm_forward(seq)                         # 主干
    if action_head == "discrete":
        bins = argmax(lm_head(hidden[-k:]))           # 每维取一个 bin
        action = dequantize(bins)                     # bin -> 实数
    else:
        noise = randn_like(action_shape)
        for step in range(num_steps):                 # 流匹配 / 扩散采样
            noise = noise + dt * action_expert(hidden, noise, t=step)
        action = noise
    return action                                     # 一段 chunk
```

看懂这段，就能判断一篇 VLA 论文的创新点落在哪：换主干、换动作头、改数据配比，还是改训练目标。
